# Spec Delta

## ADDED Requirements

### Requirement: 以人物位移判定移動
系統 SHALL 以第一次偵測到人物時的人物框中心作為基準點；之後當人物框中心與基準點的距離超過 `BM_MOTION_PX` 像素時判定為有移動，並把基準點更新為目前位置。這樣緩慢但持續的移動也會被累積判定。

#### Scenario: 人物明顯移動
- **WHEN** 人物框中心從基準點移動超過門檻
- **THEN** 該影格被判定為有移動，基準點更新為新位置

#### Scenario: 緩慢移動
- **WHEN** 人物每張影格只移動 2 像素，持續移動直到累積超過門檻（預設 20）
- **THEN** 在累積位移超過門檻的那張影格判定為有移動

#### Scenario: 人物靜止
- **WHEN** 人物框中心的位移一直在門檻內（例如偵測抖動）
- **THEN** 不判定為有移動

### Requirement: 人物消失時重設基準
系統 SHALL 在影格中偵測不到人物時清除基準點，並判定為沒有移動；之後再次偵測到人物時，以新位置作為基準，而不是直接判定為移動。

#### Scenario: 人物離開後回來
- **WHEN** 人物離開畫面幾秒後回到不同位置
- **THEN** 回來的那張影格不被判定為有移動，之後再位移超過門檻才判定為移動

## REMOVED Requirements

### Requirement: 以影格差異判定移動
**Reason**: 像素差異會被光線、影子、窗簾觸發，無法分辨是否是人在動，改以人物偵測取代。
**Migration**: 由「以人物位移判定移動」取代；移動門檻改用 `BM_MOTION_PX` 設定。CUDA 編譯器不再是建置需求。

### Requirement: 影格尺寸與初始化不符時停止處理
**Reason**: 新的影像處理會把每張影格各自縮放成模型輸入，不再依賴固定尺寸的預先配置緩衝區，尺寸改變不會造成記憶體錯誤。
**Migration**: 不需要額外處理；任意尺寸的處理行為由 `person-detection` 的「支援任意輸入尺寸」規範。
