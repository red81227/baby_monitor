# Spec Delta

## Purpose

定義系統如何從攝影機影像判定「畫面中有移動」，作為畫面標示的依據。

## ADDED Requirements

### Requirement: 啟動基準影格不觸發移動
系統 SHALL 把啟動後取得的第一張影格只當作比較基準；該影格 MUST NOT 被判定為有移動。

#### Scenario: 靜止畫面啟動
- **WHEN** 系統在畫面完全靜止的情況下啟動並處理前幾張影格
- **THEN** 沒有任何影格被判定為有移動，串流畫面上沒有出現移動標示

### Requirement: 以影格差異判定移動
系統 SHALL 比較連續兩張影格，當差異區域經去雜訊後存在面積大於 800 像素的連通區域時，判定該影格有移動，並在串流畫面上以紅框標示該區域，同時顯示 `MOTION` 文字。

#### Scenario: 物體進入畫面
- **WHEN** 一個明顯物體在攝影機前移動
- **THEN** 對應影格被判定為有移動，且串流畫面上該物體周圍出現紅框

#### Scenario: 微小雜訊
- **WHEN** 畫面中只有面積小於 800 像素的變化
- **THEN** 該影格不被判定為有移動

### Requirement: 影格尺寸與初始化不符時停止處理
系統 SHALL 在取得的影格寬、高或通道數與啟動時初始化的不同時，輸出錯誤訊息並結束，MUST NOT 以錯誤尺寸繼續處理。

#### Scenario: 攝影機回傳不同解析度
- **WHEN** 攝影機回傳的影格寬高與啟動時讀到的不同
- **THEN** 程式輸出說明尺寸不符的錯誤訊息，並以非 0 結束碼結束
