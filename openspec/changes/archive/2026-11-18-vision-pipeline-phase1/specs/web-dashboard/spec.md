# Spec Delta

## MODIFIED Requirements

### Requirement: 監視頁面
系統 SHALL 在網頁 port 的 `/` 提供監視頁面，頁面透過即時影像端點持續顯示畫面，並依偵測 metadata 在對應 `seq` 的影格上畫出人物框：判定為移動時框的顏色與靜止時不同。頁面 SHALL 顯示目前是否偵測到移動。

#### Scenario: 開啟頁面
- **WHEN** 使用者用瀏覽器開啟 `http://<host>:<BM_PORT>/`
- **THEN** 頁面以接近攝影機影格率的速度顯示畫面，以及「有移動 / 沒有移動」的狀態

#### Scenario: 人物標示
- **WHEN** 畫面中有人物
- **THEN** 頁面在人物周圍畫框；人物移動時框的顏色與靜止時不同

#### Scenario: 框不錯位
- **WHEN** 人物快速移動
- **THEN** 框畫在與偵測結果相同 `seq` 的影格上，而不是畫在較新的影格上

## ADDED Requirements

### Requirement: 顯示攝影機中斷
頁面 SHALL 在後端回報攝影機中斷時顯示攝影機中斷的訊息，並在攝影機恢復後自動恢復顯示畫面，不需要重新整理頁面。

#### Scenario: 攝影機被拔除
- **WHEN** 頁面開著時 USB 攝影機被拔除，之後再插回
- **THEN** 頁面在幾秒內顯示攝影機中斷，插回後自動恢復顯示畫面

### Requirement: 即時影像中斷後自動重連
頁面 SHALL 在即時影像連線中斷時自動重試連線，後端恢復後不需要重新整理頁面就能恢復顯示。

#### Scenario: 服務重啟
- **WHEN** 頁面開著時監視器服務被重啟
- **THEN** 服務恢復後，頁面在幾秒內自動恢復顯示畫面
