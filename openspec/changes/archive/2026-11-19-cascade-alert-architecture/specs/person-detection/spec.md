# Spec Delta

## MODIFIED Requirements

### Requirement: 偵測影格中的人物
系統 SHALL 對排程選中的影格以其子碼流執行 YOLO26n 推論，只採用類別為 person（COCO class 0）且信心值不低於設定門檻的結果，並回報信心值最高的那一個人物框，以及達到門檻的人物數量；對外回報的座標 MUST 以該影格主碼流的像素為單位。

#### Scenario: 畫面中有人
- **WHEN** 處理一張含有清楚人物、尺寸為 810x1080 的圖片
- **THEN** 系統回報至少一個人物，其框完整落在 0–810 × 0–1080 的範圍內，且框住該人物

#### Scenario: 畫面中沒有人
- **WHEN** 處理一張不含人物的影格
- **THEN** 系統回報「未偵測到人物」，人物數量為 0

#### Scenario: 非人物物體
- **WHEN** 影格中只有偵測信心很高的非人物物體（例如公車）
- **THEN** 該物體不被回報為人物，也不計入人物數量

#### Scenario: 子碼流推論、主碼流座標
- **WHEN** 主碼流為 1280x720、以縮小的子碼流推論，畫面中有人物
- **THEN** 回報的人物框落在 0–1280 × 0–720 的範圍內，畫在主碼流上時框住該人物

#### Scenario: 畫面中有多人
- **WHEN** 處理一張含有多個清楚人物的圖片（例如 `tests/data/bus.jpg`）
- **THEN** 人物數量等於信心值達到門檻的人物數，且回報的人物框是其中信心值最高的那一個
