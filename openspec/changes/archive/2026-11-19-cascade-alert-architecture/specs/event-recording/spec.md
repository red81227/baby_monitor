# Spec Delta

## Purpose

在記憶體中保留最近一段時間的主碼流影格，狀況觸發時依擷取時間取出事件前後的片段並存到磁碟，供 VLM 判定與事後查看。

## ADDED Requirements

### Requirement: 環形緩衝
系統 SHALL 在記憶體中保留最近 `BM_RING_SECONDS` 秒的主碼流影格（原始 JPEG，不重新編碼），以擷取時間索引；超過時間的影格 SHALL 被捨棄，記憶體用量不隨執行時間增加。

#### Scenario: 長時間執行
- **WHEN** 服務以 `BM_RING_SECONDS=60` 執行 1 小時
- **THEN** 環形緩衝只含最近約 60 秒的影格，行程記憶體沒有持續成長

### Requirement: 事件片段
狀況觸發時，系統 SHALL 取出擷取時間落在 `[觸發時間 - 前段, 觸發時間 + 後段]` 的影格存成一個事件片段，片段 MUST 包含每張影格的 `seq` 與擷取時間、狀況 `id`、規則版本。前段超出緩衝範圍時 SHALL 取緩衝中最早的影格開始。片段 SHALL 可透過 API 依 id 讀取。

#### Scenario: 取出片段
- **WHEN** 狀況在 t 觸發，片段範圍為前 20 秒、後 5 秒
- **THEN** 約在 t+5 秒後產生片段，影格的擷取時間介於 t-20 秒與 t+5 秒之間且依時間排序

#### Scenario: 攝影機中斷期間
- **WHEN** 片段範圍內有一段攝影機中斷
- **THEN** 片段只包含實際有擷取到的影格，不補空白影格

### Requirement: 片段保留上限
事件片段占用的磁碟空間 SHALL 不超過 `BM_EVENT_MAX_MB`；超過時 SHALL 從最舊的片段開始刪除。

#### Scenario: 空間滿了
- **WHEN** 新片段寫入後總大小超過上限
- **THEN** 最舊的片段被刪除，直到總大小回到上限以下
